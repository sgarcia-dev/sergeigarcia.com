Luxoft is a software services company. From its Guadalajara office I worked as a Full-Stack Engineer for two travel clients: Expedia, on its booking and advertising products, and HomeAway, on a new hospitality app.

### What I did

- Made a legacy Expedia booking flow easier to maintain using functional programming practices.
- Built React, Redux, Node.js and Express features for a global ad-serving platform.
- Introduced Selenium and Puppeteer browser automation, with a reported 300% improvement in testing speed. It cut down on slow manual test runs and made changes easier to check.
- Compared testing tools for a React codebase and recommended Jest and WebdriverIO.
- Led development of a hospitality wizard MVP for HomeAway, using React, Apollo and GraphQL with a Hapi.js GraphQL server.

### What I learned

GraphQL was new to me when the HomeAway project started. I learned it while delivering the project, and it became a core part of my work in the roles that followed.
