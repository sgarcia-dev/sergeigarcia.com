Teaching.com runs Typing.com, which teaches typing and digital literacy on a platform serving <span class="lv-mark">35M+ monthly users</span>. Schools and districts use its teacher portal to manage classes, assignments and student progress. As Lead Frontend Engineer, working remotely, I led the modernization of two products: the teacher portal and an internal customer service dashboard.

### What I did

- Rebuilt both front ends with React, Tailwind and Headless UI, replacing <span class="lv-mark">an aging Backbone.js codebase</span> while working alongside the existing PHP and Laravel back end.
- Started with the smaller customer service dashboard, then <span class="lv-mark">led the full teacher portal rewrite</span>. The new React app ships as a bundle inside the existing Laravel pages, so there was no risky switch-over day.
- Chose React Query to keep data fetching and caching simple, and re-planned the app around it when an early architecture turned out too complex.
- Built a shared design system component library in Storybook that follows the Figma designs.
- Set up a PR process, issue triage and quality checks: ESLint accessibility rules, pre-commit hooks, a pull request template and Storybook interaction tests.
- Designed a GraphQL API architecture proposal for the migration work, with a working demo and a risk analysis to evaluate the approach.
- Used Shape Up to turn complex stakeholder requests into manageable work, and gave weekly demo-style updates so people understood project decisions and challenges.

### Mentoring and teamwork

- Guided a front end developer and a designer/developer through the work.
- Turned a long disagreement over the teacher portal's React architecture into an agreed direction by laying out the trade-offs and working through them with leadership.
- Mentored colleagues and helped the team build more consistent front end practices.
